📝 Notes — MarkUps · 0.1.0

Both visible and hidden notes go to the model as a system message. These positions control context, not where notes appear in an RP post.
Attach notes from another chat of this card

Replaces the attachment with the same key in this chat. Other notes stay attached. Detaching only removes this chat's link.

Commands and built-in regex

One RP reply can include any number of these commands. Only attached instances are available. IDs use letters, numbers, underscores or hyphens.

[mu:set visible groceries]
Milk, bread, a brass key.
[/mu]
[mu:delete visible groceries]
[mu:show visible start]
[mu:show visible end]
[mu:show visible here]
[mu:hide hidden]
[mu:limit hidden 1024]

Set creates or replaces one entry. Show/hide controls the whole instance. Put show … here where the note should appear. Inline instances without a marker appear at the end. A limit is a content budget: over-budget data is kept and highlighted, never silently cut.

MarkUps installs one named ST Regex rule for display/prompt cleanup, including unfinished streaming commands. No manual regex setup is needed. After processing, commands leave the message text and are retained in its MarkUps metadata. Opening an old chat does not execute them again.

Import / Export — editable Markdown

Open the .md file in any text editor, or write your own. Plain .txt is accepted too. No JSON, UUIDs or escaping quotes.

Paste or write notes directly
File example
# MarkUps

## Note: visible
Title: Shopping list
Visible: yes
Post: end
Limit: 512

### Entry: groceries
Milk, bread, a brass key.

## Note: hidden
Visible: no

### Entry: plot
The shopkeeper secretly works for the rival guild.

Instances and chat attachments are stored in this character card's MarkUps extension data. Card exports contain both visible and hidden notes. Hidden means omitted from the RP post, not hidden from the player in these settings. Chat metadata stores this chat's attachment ID.
